## Code changes made after the observation

These changes are on disk but were not loaded into the live process used above:

- One shared covariance LCMV solver remains; there is no covariance-free implementation.
- The selectable ideal-angle-only bladeRF preserve mode was removed.
- The product now associates a fresh measured healthy U1 with the stable live bladeRF angle cluster and freezes that measured vector/covariance at enable time.
- Enabling LCMV arms uniform output first.
- Activation requires both an input-power rise and a generalized covariance-mode rise; angle alone is explicitly forbidden.
- Jammer detection latches until LCMV is disabled.
- Target weights use a one-second complex linear chunk ramp. Every ramp point preserves the same measured-U1 complex response because both endpoints obey that equality constraint.
- Covariance updates cannot restart an active target ramp. Safety fallback,
  operator disable, and other protective transitions can still preempt it.
- The obsolete desired-signal-loss rejection guard and both of its configuration
  parameters were removed. Desired loss remains a displayed diagnostic; it
  cannot silently replace an otherwise valid covariance-LCMV target with uniform
  weights.
- Jammer-excess suppression is now estimated from the PSD-projected covariance
  difference between current jammer-latched covariance and the frozen jammer-off
  covariance. It is labeled separately from total output reduction, which still
  includes wanted-signal loss.
- Every decimated TrackingMonitor update is now persisted to
  `<log_dir>/tracking-state/tracking_<UTC>_<pid>.jsonl`, including prompt I/Q,
  C/N0, Doppler, carrier phase, code phase, tracking sample counter, validity,
  180-degree PLL lock, and cycle-slip flags.
- GUI states distinguish ARMED, ACTIVATING, ON/jammer-latched, and safety FALLBACK.
- The GUI no longer displays UTM east/north or the ambiguous single-fix
  `PVT accuracy` field. It retains latitude/longitude, altitude, time, DOP, and
  satellite counts, and adds truth-referenced empirical CEP50/CEP95 once the
  configured accuracy window is full.
- Automated result after the changes: 249 tests passed, 1 hardware-dependent test skipped.
